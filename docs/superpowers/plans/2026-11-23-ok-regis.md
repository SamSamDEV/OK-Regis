# OK Régis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build OK Régis, a Windows tray app that listens (offline, French, Vosk) for spoken commands and drives OBS through its WebSocket server, answering with a voice.

**Architecture:** Three projects. `OkRegis.Core` holds all hardware-free logic (text matching, spoken forms, command parsing, grammar building, command execution, orchestration) behind small interfaces (`IObsClient`, `IMicListener`, `IResponder`, `IObsProcessWatcher`, `ISecretProtector`). `OkRegis.App` (WinForms) holds the real implementations (OBS WebSocket, NAudio+Vosk, Windows voices, tray, windows). `OkRegis.Tests` (xUnit) tests Core with fakes. Everything is event-driven; the only timer is the 3 s `obs64.exe` check.

**Tech Stack:** .NET 10 LTS (latest LTS at 2026-11-23), C#, WinForms, xUnit, `OBSWebsocketDotNet` (NuGet), `Vosk` (NuGet) + `vosk-model-small-fr`, `NAudio`, `System.Speech`, DPAPI (`System.Security.Cryptography.ProtectedData`).

**Spec:** Design doc "OK Régis : conception" of 2026-11-23, https://github.com/SamSamDEV/OK-Regis (section numbers below refer to it). Code comments are written in French.

## Global Constraints

- Windows 10/11 x64, no admin rights, self-contained publish in one folder (§7).
- Performance first: < 120 Mo RAM, CPU ≈ 0 % idle, no busy loops, no GPU speech recognition, no Whisper, no Electron (§2, §5).
- Régis is a separate app, never an OBS plugin (§4).
- 100 % local, French only, no generative AI (§2, §3).
- Vosk with `vosk-model-small-fr` (~40 Mo), mic captured 16 kHz mono with NAudio, grammar restricted to useful words plus `[unk]` (§6.3).
- OBS WebSocket v5 (OBS 28+), password encrypted with DPAPI, auto-reconnect (§6.2).
- Phrase form: `[ok|hey] <nom> <commande>`; matching is lowercase, accent- and punctuation-insensitive, small typos tolerated (§6.4).
- Every command type is individually toggleable; **stream commands are disabled by default**. Volume step default 3 dB (§6.4).
- Actions target the **currently displayed scene** only; groups included (§6.4).
- Never listen while Régis speaks; unknown or low-confidence phrase → do nothing, log it in history (§6.3).
- Settings in `%AppData%\OK-Regis\settings.json` (§6.7). Autostart via `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, optional (§6.1).
- OBS process check every ~3 s on `obs64.exe`; mic closed while idle (§6.1).
- Resource box refreshed every 1 s **only while the window is visible** (§6.6).
- Code readable by a beginner: simple structure, clear names, French comments (§2).

## Review Focus

1. Names with only symbols/emoji or accents (`"🎮"`, `"Écran Été"`, `"Texte (GDI+) 2"`): must normalize to something usable or be flagged unspeakable, never crash or produce an empty grammar word.
2. Two scenes/sources/nicknames normalizing to the same string (`"AFK"` and `"afk"`): parser picks deterministically and the UI shows the clash; never throws.
3. OBS closes or WebSocket drops mid-command: executor returns a failure result, app goes to Idle/reconnects, no unhandled exception, no stuck microphone.
4. Assistant name equal to, or a typo of, a command verb or scene name (`"mets"`, `"lol"`): wizard rejects or warns; parser does not misfire.
5. Régis hearing itself: audio captured during playback is discarded; a second launch of the app must not start a second instance with its own mic.
